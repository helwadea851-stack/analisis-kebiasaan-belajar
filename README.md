# Analisis Kebiasaan Belajar Mahasiswa pada Masa Ujian

## Deskripsi
Penelitian ini bertujuan untuk mengetahui kebiasaan belajar mahasiswa selama masa ujian. Data penelitian diperoleh melalui penyebaran kuesioner online menggunakan Google Form.

## Metode Penelitian
Metode yang digunakan adalah survei online dengan teknik non-probability sampling. Responden penelitian merupakan mahasiswa ntb yang mengisi kuesioner secara sukarela.

## Instrumen Penelitian
Instrumen penelitian menggunakan skala Likert dengan rentang nilai 1–5:
- 1 = Sangat Tidak Setuju
- 2 = Tidak Setuju
- 3 = Netral
- 4 = Setuju
- 5 = Sangat Setuju

## Analisis Data
Analisis data dilakukan menggunakan SPSS, meliputi:
- Uji validitas
- Uji reliabilitas
- Analisis deskriptif
- Tabel frekuensi
- Visualisasi data menggunakan grafik

## Hasil Penelitian
Hasil uji validitas menunjukkan seluruh item pernyataan valid karena memiliki nilai Corrected Item-Total Correlation > 0,30.

Hasil uji reliabilitas menunjukkan nilai Cronbach’s Alpha sebesar 0,929 sehingga instrumen penelitian dinyatakan sangat reliabel.

Berdasarkan analisis deskriptif, mayoritas mahasiswa memiliki kebiasaan belajar yang cukup baik selama masa ujian.
